Erreurs JSX fréquentes

Retour multiple sans wrapper
return <h1>A</h1> <p>B</p>   // ERREUR
return <><h1>A</h1><p>B</p></>   // OK
Oubli du return dans arrow function
items.map(i => { <li>{i.name}</li> })  // ERREUR : pas de return
items.map(i => <li>{i.name}</li>)     // OK : implicite sans {}
items.map(i => { return <li>{i.name}</li> })  // OK : return explicite
Nombre affiché directement (0 s'affiche)
{items.length && <List />}  // affiche "0" si vide
{items.length > 0 && <List />}  // OK

useEffect — fetch au montage

useEffect(() => {
  const fetchData = async () => {
    setLoading(true)
    try {
      const res = await fetch('/api/tickets')
      const data = await res.json()
      setTickets(data)
    } catch (e) {
      setError("Erreur de chargement")
    } finally {
      setLoading(false)
    }
  }
  fetchData()
}, [])   // [] = exécuté 1 seule fois au montage
useEffect ne peut pas être async directement

useEffect — dépendances

useEffect(() => { ... }, [])          // 1 fois au montage
useEffect(() => { ... }, [id])        // à chaque changement de id
useEffect(() => { ... })              // à chaque render (éviter)

Pattern complet composant avec fetch

const TicketList = () => {
  const [tickets, setTickets] = useState<Ticket[]>([])
  const [loading, setLoading] = useState(true)
  const [error, setError] = useState<string | null>(null)

  useEffect(() => {
    fetch('/api/tickets')
      .then(r => r.json())
      .then(setTickets)
      .catch(() => setError("Erreur"))
      .finally(() => setLoading(false))
  }, [])

  if (loading) return <p>Chargement...</p>
  if (error) return <p>{error}</p>
  return <ul>{tickets.map(t => <li key={t.id}>{t.name}</li>)}</ul>
}

Gestion erreurs try/catch complète

const loadTickets = async () => {
  setLoading(true)
  setError(null)
  try {
    const res = await fetch('/api/tickets')
    if (!res.ok) throw new Error(`Erreur ${res.status}`)
    const data = await res.json()
    setTickets(Array.isArray(data) ? data : [])
  } catch (e) {
    setError(e instanceof Error ? e.message : "Erreur inconnue")
  } finally {
    setLoading(false)
  }
}

Erreurs fréquentes React + TS

Cannot read properties of undefined (map)

const [data, setData] = useState()    // undefined par défaut
data.map(...)                          // CRASH
const [data, setData] = useState<Ticket[]>([])  // init tableau vide
(data || []).map(...)                  // défense supplémentaire

Each child should have a unique "key" prop

items.map(i => <li>{i.name}</li>)
items.map(i => <li key={i.id}>{i.name}</li>)
items.map((i, idx) => <li key={idx}>{i.name}</li>)  // idx si pas d'id
key={idx} déconseillé si la liste est réordonnée/modifiée

JSX return oublié dans map

items.map(i => {
  <li key={i.id}>{i.name}</li>    // {} sans return = undefined
})
items.map(i => (                   // () implicite : OK
  <li key={i.id}>{i.name}</li>
))
items.map(i => <li key={i.id}>{i.name}</li>)  // 1 ligne : OK

String + number = concaténation

const total = "100" + "50"    // "10050" pas 150
const total = Number("100") + Number("50")   // 150
const total = +"100" + +"50"                 // 150

useEffect async directement

useEffect(async () => {       // INTERDIT — warning React
  const data = await fetch(...)
}, [])
useEffect(() => {
  const load = async () => { const data = await fetch(...) }
  load()
}, [])

State mis à jour mais composant pas re-render

tickets.push(newTicket)       // mutation directe = pas de re-render
setTickets(tickets)           // même référence = React ignore
setTickets([...tickets, newTicket])      // nouvelle référence
setTickets(prev => [...prev, newTicket]) // forme fonctionnelle
